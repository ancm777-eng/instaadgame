# Guide 03 — 몬스터 & 25 Stage / 5 Phase 디펜스 명세 (Monster Guide)

> **구현 원칙**: 총 **25 Stage**를 5개씩 묶어 **5 Phase**로 구성한다. 각 Phase는 고유 테마(숲속 동물 → 오크 → 좀비 → 뱀파이어 → 악마)를 가지며, 각 Phase의 5번째 Stage(Stage 5, 10, 15, 20, 25)는 **보스 Stage**로 동작한다.

---

## 1. 웨이브 & Stage 타이밍 규칙

| 항목 | 명세 수치 | 코드 상수명 권장 |
|---|---|---|
| 전체 Stage 수 | **25 Stage** (Phase 1~5 × 각 5 Stage) | `TOTAL_STAGES = 25` |
| **Stage 1 시작 대기 시간** | 게임 시작 후 **5분 (300초)** | `FIRST_STAGE_DELAY = 300` |
| **Stage 종료 후 휴식 시간** | 이전 Stage 완전 종료 후 **1분 30초 (90초)** | `STAGE_BREAK_INTERVAL = 90` |
| **즉시 시작 (템포 조절)** | 대기/휴식 중 언제든 **`⚡ 다음 Stage 즉시 시작`** 버튼으로 웨이브 즉시 호출 가능 (조기 호출 보너스 캐시 `Stage × 30원`) | `startNextStageNow()` |
| **각 전투 Stage 스폰 지속 시간** | **1분 (60초)** | `STAGE_BATTLE_DURATION = 60` |
| **스폰 주기** | **10초마다 1회** (1분간 총 6회 스폰) | `SPAWN_TICK_INTERVAL = 10` |
| **일반 Stage 스폰 수량** | 10초마다 **5마리** (총 30마리 / Stage) | `NORMAL_SPAWN_COUNT = 5` |
| **보스 Stage 스폰 규칙** | Stage 시작 시 **커다란 보스 1마리** 즉시 출현 + 10초마다 해당 Phase의 **일반 몬스터 4종이 각 1마리씩(총 4마리/10초)** 동시 출현 | `BOSS_ESCORT_PER_KIND = 1` |

- **모바일 압축 모드 지원**: 상수(`STAGE_BATTLE_DURATION`, `STAGE_BREAK_INTERVAL`)를 설정값으로 분리해, 필요 시 60초 전투 / 60초 휴식으로 빠르게 조절할 수 있도록 구현한다.

## 2. 보스 몬스터 스킬 진화 단계 면역 규칙 (핵심 기믹)

각 Phase의 보스 몬스터(Stage 5, 10, 15, 20, 25)는 **요구 스킬 진화 단계 미만**의 공격에 대해 **완전 면역(데미지 0, `🛡️ 스킬 N단계 필요!` 경고)** 처리된다.

| Phase | 보스 Stage | 보스 이름 | 데미지 적용 최소 스킬 단계 | 면역 시 피드백 |
|---|---|---|---|---|
| **Phase 1** | Stage 5 | **고대 숲의 곰왕** | **스킬 2단계** 이상 | `🛡️ 스킬 2단계부터 데미지!` |
| **Phase 2** | Stage 10 | **대족장 오크 워로드** | **스킬 3단계** 이상 | `🛡️ 스킬 3단계부터 데미지!` |
| **Phase 3** | Stage 15 | **네크로 타이탄** | **스킬 4단계** 이상 | `🛡️ 스킬 4단계부터 데미지!` |
| **Phase 4** | Stage 20 | **진조 블러드 로드** | **스킬 5단계** 이상 | `🛡️ 스킬 5단계부터 데미지!` |
| **Phase 5** | Stage 25 | **심연의 대마왕** | **스킬 6단계 (최종)** | `🛡️ 최종 6단계(창세 연성술) 필요!` |
