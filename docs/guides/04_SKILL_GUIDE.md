# Guide 04 — 스킬 진화 시스템 & 시각 이펙트 명세 (Skill Evolution Guide)

> **용어 규칙**: UI 및 코드 내 모든 텍스트에서 `"스킬 해금"`이라는 표현을 사용하지 않고, 반드시 **`"스킬 진화"`**로 통일한다.

---

## 1. 스킬 진화 구조 및 규칙

- 스킬은 단일 연금술 계통의 **1단계 ~ 6단계(최종)** 진화 트리로 구성된다.
- **레벨업 & 진화 조건**:
  - 1~5단계는 각각 **Lv.1 → Lv.2 → Lv.3**까지 레벨업할 수 있다.
  - 현재 단계의 **Lv.3**을 달성하면, 다음 단계의 **Lv.1로 [스킬 진화]** 버튼이 활성화된다.
  - 6단계(최종)는 단일 최종 진화(MAX)로 완성된다.
- **시스템 연동 조건**:
  - **보스 면역 돌파**: Phase 1 보스(2단계~) / Phase 2 보스(3단계~) / Phase 3 보스(4단계~) / Phase 4 보스(5단계~) / Phase 5 최종 보스(6단계)
  - **연구실 증축 조건 (순환 데드락 방지 확정)**:
    - 몽글몽글 연구실 **Lv.3**: **스킬 2단계 Lv.3** 달성 시 업그레이드 가능
    - 몽글몽글 연구실 **Lv.5**: **스킬 4단계 Lv.3** 달성 시 업그레이드 가능

## 3. 단계별 시각 이펙트(VFX) & 3D 연출 구현 명세

### 1단계 — 기초 원소 조합 (`4원소: 불·물·바람·땅`)
- **연출 명세**: 발밑에 작은 마법진이 생기고 빨강·파랑·초록·노랑 원소 방울이 톡톡 튀며 합쳐지는 연출
- **3D 구현**: 발밑(`y = 0.08`, r=`1.4m`) 회전 4원소 마법진 + 4색 오브 포물선 합체 후 원소탄 발사.

### 2단계 — 다중 원소 증폭 (`4원소 + 별가루`)
- **연출 명세**: 원소 방울들이 회오리처럼 빠르게 돌며 은은한 별빛 가루가 흩날리고, 지팡이 끝이 빛나는 연출
- **3D 구현**: 4색 원소 방울 고속 나선 공전(Vortex) + 라벤더/실버 별빛 글리터 파티클 + 지팡이 끝 플레어 광원.

### 3단계 — 황금 연성술 (`원소 융합 + 황금`)
- **연출 명세**: 바닥에 황금색 연성진이 넓게 펼쳐지면서 주위로 금빛 파동과 톱니바퀴 잔상이 퍼지는 연출
- **3D 구현**: 메탈릭 골드 대형 연성진(r=`3.5m`) + 동심원 금빛 충격파 + 반투명 황금 톱니바퀴(Gear Mesh) 잔상 확산.

### 4단계 — 현자의 연성술 (`현자의 돌 개방`)
- **연출 명세**: 머리 위에 붉은 '현자의 돌' 환영이 떠오르며, 무지갯빛 빛줄기가 쏟아져 내리는 연출
- **3D 구현**: 영웅 머리 위(`y = 2.8m`) 루비 크림슨 다면체 현자의 돌 부유·자전 + 적 상공에서 7색 프리즘 빛줄기 수직 낙하 폭발.

### 5단계 — 차원 초월 연성 (`모든 원소 + 차원 에너지`)
- **연출 명세**: 하늘에 작은 차원의 문이 열리고, 별빛과 황금, 원소들이 하나로 융합해 거대한 빛기둥을 뿜어내는 연출
- **3D 구현**: 전장 상공(`y = 6.5m`) 보라·청록빛 차원의 문 개방 + 원소/별빛/황금 융합 후 거대 차원 빛기둥(Mega Beam Pillar) 관통.

### 6단계 (최종) — 창세 연성술 / 우주 창조 연성 (`차원 에너지 + 창조의 빛`)
- **연출 명세**: 화면 전체가 은하수 빛으로 물들며 거대한 입체 마법진이 회전하고, 중앙에서 작은 우주(행성·별무리)가 탄생하며 폭발하듯 빛이 퍼지는 연출
- **3D 구현**: 화면/배경 은하수 네뷸라 글로우 + 상공 3축 교차 거대 입체(3D) 마법진 + 중앙 미니 우주(행성·고리·별무리) 응축 탄생 후 초신성 광파 전장 전체 폭발.
