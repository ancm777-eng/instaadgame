2. 채집 원재료 자원 (총 8종)
================================================================================
※ 공통 규칙: 모든 자원 노드는 내구도(HP) 2이며, 파괴 후 4.2초 뒤 재생성됩니다.
   영웅, 요정 일꾼, 수확 트럭이 모두 채집·운반할 수 있습니다.

1) 푸른 광석 (blue_ore / ⛏️ / 기본 가치 💵 10)
   - 습득법:
     · Zone 1 (기본 해금, 24노드)
     · Zone 3 (심층 광산 확장 'farm2' 해금 시 +18노드)
   - 활용처:
     · 원석 교역소 직판 (개당 💵 10)
     · 제1연금술 연구소 투입 → 차원 에너지 연성
     · 1호기 크리스탈 세공기 투입 → 세공 보석 제작
     · 3호기 엘릭서 증류솥 투입 (광석 + 무지개 약초) → 황실 엘릭서 제작

2) 무지개 약초 (rainbow_herb / 🌿 / 기본 가치 💵 10)
   - 습득법:
     · Zone 2 (2호기 완공 또는 약초 숲 해금 시 24노드)
     · Zone 4 (심층 약초 확장 'farm3' 해금 시 +18노드)
   - 활용처:
     · 2호기 무지개 포션 양조기 투입 → 마법 포션 제작
     · 3호기 엘릭서 증류솥 투입 (광석 + 무지개 약초) → 황실 엘릭서 제작
     · 5호기 정령 오르골 조립기 투입 (약초 + 정령의 이슬) → 정령 오르골 제작

3) 화염 마나석 (fire_mana_stone / 🔥 / 기본 가치 💵 45) · [Era 2 / Wave 6+]
   - 습득법: Zone 5 (18노드)
   - 활용처:
     · 제2연금술 연구소 투입 → 차원 에너지 연성 (×2 배수)
     · 4호기 마나 룬 프레스 투입 (세공 보석 + 화염 마나석) → 화염 룬스톤 제작

4) 정령의 이슬 (spirit_dew / 💧 / 기본 가치 💵 55) · [Era 2 / Wave 6+]
   - 습득법: Zone 6 (18노드)
   - 활용처:
     · 5호기 정령 오르골 조립기 투입 (약초 + 정령의 이슬) → 정령 오르골 제작
     · 7호기 달빛 향수 증류탑 투입 (달빛 버섯 + 정령의 이슬) → 달빛 향수 제작

5) 번개 수정 (lightning_crystal / ⚡ / 기본 가치 💵 110) · [Era 3 / Wave 11+]
   - 습득법: Zone 7 (18노드)
   - 활용처:
     · 제3연금술 연구소 투입 → 차원 에너지 연성 (×3 배수)
     · 6호기 번개 마도핵 충전소 투입 (마법 포션 + 번개 수정) → 번개 마도핵 제작

6) 달빛 버섯 (moon_mushroom / 🍄 / 기본 가치 💵 140) · [Era 3 / Wave 11+]
   - 습득법: Zone 8 (18노드)
   - 활용처:
     · 7호기 달빛 향수 증류탑 투입 (달빛 버섯 + 정령의 이슬) → 달빛 향수 제작

7) 별똥별 운석 (star_meteorite / 🌟 / 기본 가치 💵 350) · [Era 4 / Wave 16+]
   - 습득법: Zone 9 (18노드)
   - 활용처:

   - 습득법: 6호기 번개 마도핵 충전소 (재료: 마법 포션 1 + 번개 수정 1 / 제작 2.2초)

   - 활용처: 왕실 특사 가판대 고객 초고속 자동 판매 (💵 11,000, 판매 쿨타임 0.45초)

8) 현자의 돌 (philosopher_stone / 💎👑 / 기본 💵 30,000 · 4연구소 시 💵 60,000) · [Era 4]
   - 습득법: 8호기 현자의 돌 융합로 (재료: 별똥별 운석 1 + 용의 비늘꽃 1 + 번개 마도핵 1 / 제작 2.5초)
